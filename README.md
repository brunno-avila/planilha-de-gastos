O que é possível fazer

- Adicionar gastos com descrição, valor, categoria e data.
- Ver os gastos registrados na tabela.
- Filtrar os gastos por mês e categoria.
- Editar a descrição e o valor de um gasto.
- Excluir um gasto.
- Definir um orçamento mensal.
- Ver o total gasto e o saldo disponível.

## Salvamento dos dados

Os gastos e o orçamento são salvos no `localStorage` do navegador. Isso permite que continuem disponíveis ao atualizar ou fechar e abrir a página no mesmo navegador e dispositivo.

Os dados não são compartilhados entre navegadores ou dispositivos. Limpar os dados do navegador também pode apagá-los.

## Tecnologias

- HTML: estrutura da página.
- CSS: aparência e adaptação para telas menores.
- JavaScript: cadastro dos gastos, cálculos, filtros e salvamento no navegador.

## Observação sobre valores

Ao definir o orçamento, use ponto para separar os centavos. Por exemplo: `1500.50`.
